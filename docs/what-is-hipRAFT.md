# What is hipRAFT?

hipRAFT is a library of functions for machine learning and data mining.  It is AMD’s ROCm-native
port of NVIDIA® RAPIDS® RAFT: a collection of reusable, GPU-accelerated C++/Python primitives (distance, reductions,
neighbors, graph, sparse/dense linalg, etc.) built with HIP for AMD Instinct GPUs. It provides
RAFT-compatible APIs so data-science and ML libraries (e.g., vector search, clustering, graph analytics)
can run efficiently on ROCm without code rewrites. While not exhaustive, the following table summarizes
the accelerated functions in hipRAFT:

| Module     | Headers                     | Description                                                                                                                                                                                                                                                                                                                                |
|------------|-----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [**Core**](./reference/cpp_api/core)   | [`cpp/include/raft/core/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/core)   | <ul><li>Spans, buffers, and memory allocation policies and containers.</li><li>GPU Resource Management – Streams, events, device properties.</li><li>Logging & Debugging – Logging macros, profiling utilities.</li><li>Sparse Dense Matrix Abstractions – COO and CSR matrix handling.</li><li>Known issues:<ul><li>The API in `raft/core/interruptible.hpp` are not supported.</li></ul></li></ul>                                       |
| **Label** | [`cpp/include/raft/label/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/label) | These APIs provide functionalities for handling and processing class labels in machine learning and graph-based algorithms. They focus on extracting unique labels, mapping labels to a monotonically increasing order, and merging different label sets. |
| [**Linear Algebra**](./reference/cpp_api/linalg) | [`cpp/include/raft/linalg/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/linalg) | APIs that abstract common BLAS routines, standard linear system solvers, factorization and eigenvalue solvers.<ul><li>Known issues:<ul><li> `raft::linalg::randomized_svd` is not supported.</li></ul></li></ul>                                                                                                                                                                                                                        |
| [**Matrix**](./reference/cpp_api/matrix) | [`cpp/include/raft/matrix/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/matrix) | The hipRAFT matrix API extends matrix operations beyond `raft::linalg`, offering utilities for arithmetic (power, ratio, reciprocal, sign-flip, square root), manipulation (initialization, reversing, thresholding), ordering (argmax, argmin, select-K, sorting), and reductions (matrix norms).                                       |
| [**Solver**](./reference/cpp_api/solver) | [`cpp/include/raft/solver/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/solver) | Solvers supported: <ul><li>`LinearAssignmentProblem` solver(alternating tree Hungarian Algorithm) from `cpp/include/raft/solver/linear_assignment.cuh`</li><li>`Minimum spanning tree` solver is supported from `cpp/include/raft/sparse/mst/mst.hpp`</li></ul>                                                                   |
| [**Sparse**](./reference/cpp_api/sparse) | [`cpp/include/raft/sparse/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/sparse) | Provides GPU-accelerated operations for sparse matrices, including arithmetic, normalization, multiplication, slicing, and solvers for eigenvalues and graph problems, optimizing large-scale computations.<ul><li>Known issues:<ul><li> `raft::sparse::linalg::masked_matmul` is not supported for `half` type. </li></ul></li></ul>                                                                                                    |
| **Utilities** | [`cpp/include/raft/util/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/util)   | Miscellaneous utility/helper functions                                                                                                                                                                                                                                                                                                 |
| **Common** | [`cpp/include/raft/common/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/common) | Miscellaneous common functions used across various modules.                                                                                                                                                                                                                                                                            |
| [**Random**](./reference/cpp_api/random) | [`cpp/include/raft/random/*`](https://github.com/ROCm-DS/hipRaft/tree/release/rocmds-25.10/cpp/include/raft/random) | Miscellaneous functions for random number generation.<ul><li>Known issues:<ul><li> `raft::random::make_regression` is not supported for the `double` type. </li></ul></li></ul>                                                                                                                                                                                                                                                                                  |
